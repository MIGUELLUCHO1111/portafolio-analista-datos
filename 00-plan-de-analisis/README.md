# Proyecto 00 · Plan de análisis

Antes de abrir Excel o escribir una consulta, un analista profesional **define qué va a responder y cómo lo va a medir**. Este proyecto es la base de todos los demás.

## Archivos

- [`plan_analisis_ventas.md`](plan_analisis_ventas.md) · plan completo del análisis de ventas (ejemplo resuelto)
- [`plantilla_plan_analisis.md`](plantilla_plan_analisis.md) · plantilla vacía para tus propios análisis
- [`diccionario_de_datos.md`](diccionario_de_datos.md) · descripción de cada columna de `datos/`

## Qué demuestra

- Convertir una solicitud vaga en **preguntas SMART**
- Definir **KPIs** con su fórmula exacta
- Documentar fuentes, supuestos y riesgos de calidad
- Mantener una **bitácora** de decisiones

## Tu turno

1. Lee el plan resuelto y la plantilla.
2. Elige un tema de tu trabajo (con datos **anonimizados**) o un dataset público.
3. Copia la plantilla como `plan_mi_analisis.md` y complétala.
4. Escribe el diccionario de datos de tu dataset.
5. Súbelo: `git add . && git commit -m "Plan de análisis propio" && git push`
