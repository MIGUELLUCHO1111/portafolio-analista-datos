# Fuentes de los datos

Descargados el 17/10/2026 con `actualizar_datos.py`.

| Archivo | Fuente | Contenido |
|---|---|---|
| `produccion_mensual.csv` | [Sodir FactPages](https://factpages.sodir.no) · licencia NLOD | Producción mensual neta por campo desde 1971 (petróleo, gas, NGL, condensado y agua) |
| `reservas.csv` | Sodir FactPages | Reservas recuperables y remanentes por campo (estimación oficial) |
| `campos.csv` | Sodir FactPages | Operador, estado, área y tipo de hidrocarburo de cada campo |
| `brent_mensual.csv` | [FRED, serie POILBREUSDM](https://fred.stlouisfed.org/series/POILBREUSDM) | Precio promedio mensual del Brent (USD/bbl) |

Unidades de Sodir: millones de metros cúbicos estándar (MSm³). 1 Sm³ = 6,2898 barriles.
