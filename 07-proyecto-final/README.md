# Proyecto 07 · Mi proyecto final con datos abiertos

Este es **tu** proyecto: eliges un tema que te interese, aplicas todo el flujo de análisis y lo publicas. Es el proyecto que vas a mostrar en entrevistas.

## Dónde conseguir datos gratuitos
| Fuente | Qué tiene |
|---|---|
| [datos.gov.co](https://www.datos.gov.co) | Datos abiertos de Colombia |
| [datos.gob.mx](https://datos.gob.mx) | Datos abiertos de México |
| [datos.gob.es](https://datos.gob.es) | Datos abiertos de España |
| [data.worldbank.org](https://data.worldbank.org) | Indicadores económicos y sociales por país |
| [kaggle.com/datasets](https://www.kaggle.com/datasets) | Miles de datasets para practicar (cuenta gratuita) |
| [ourworldindata.org](https://ourworldindata.org) | Salud, energía, educación y más |

Consejo: elige un tema relacionado con tu sector (por ejemplo energía, transporte o petróleo y gas). Eso hace tu portafolio más relevante para tu carrera.

## Fases y entregables
| Fase | Herramienta | Entregable |
|---|---|---|
| 1. Plan | Plantilla del proyecto 00 | `plan.md` con 3–5 preguntas SMART y KPIs |
| 2. Obtener datos | Descarga, API o scraping | `datos/` + de dónde salieron |
| 3. Limpiar | Python (pandas) o Power Query | `limpieza.ipynb` con cada paso explicado |
| 4. Analizar | SQL y/o pandas | consultas o celdas que respondan cada pregunta |
| 5. Visualizar | Power BI o dashboard web | `.pbix` y captura, o página publicada |
| 6. Comunicar | README | hallazgos, recomendación y limitaciones |

## Lista de verificación final
- [ ] Las preguntas están respondidas con números
- [ ] Los totales coinciden entre herramientas
- [ ] El README explica datos, método, hallazgos y limitaciones
- [ ] Los gráficos tienen títulos que dicen la conclusión
- [ ] No hay datos personales ni confidenciales
- [ ] Está publicado y fijado en tu perfil de GitHub
